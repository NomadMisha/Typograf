# История изменений

## 14 октября 2026 — локальный нейросетевой модуль

- Добавлен адаптер Ollama с локальной моделью Qwen3 4B и JSON-схемой предложений.
- На экране результата появилась отдельная нейропроверка с объяснениями и ручным применением правок.
- Добавлены проверка точных цитат и позиций, защита кода/ссылок/чисел/отрицаний, отмена и отбрасывание устаревших ответов.
- Добавлен запуск на Mac через `start-neural.command`. Движок и веса хранятся локально в исключённой из Git папке.
- Интеграция доступна через локальный сервер; однофайловая и Pages-версии сообщают о способе запуска.
- Проверена реальная обработка на CPU после отказа Metal, сохранены результаты семи диагностических примеров и обнаруженный оставшийся пропуск. Пунктуационные предложения с подменой слов блокируются.

## 14 октября 2026 — аудит языковых исправлений

- Словарные и онлайн-подсказки для неизвестных слов требуют выбора редактора; неоднозначное «Крипис» больше не заменяется принудительно.
- Сохраняется верхний регистр. Защищены почта, технические идентификаторы и имена файлов.
- Ограничены ложные запятые в устойчивых сочетаниях и неверная замена «в течении» перед нетемпоральным существительным.
- Финальная точка стала предложением с возможностью явного применения.
- Исправлен подсчёт обнаруженных ошибок: предупреждение о другом фрагменте не даёт зачёта за размеченную ошибку.
- Добавлены 50 синтетических регрессионных и 16 отложенных диагностических примеров с явным указанием, что редактор их не проверял; подготовлено сравнение до и после.
- Прошли 88 сценариев приложения и отдельный тест измерения качества. Реальный редакторский набор остаётся пустым.

## 14 октября 2026 — документы и JSON

- Добавлен блок «Мои документы»: сохранение, открытие и удаление результатов с подтверждением.
- Подтверждённые результаты автоматически сохраняются в истории браузера.
- Добавлены экспорт и импорт JSON. Повторный импорт не создаёт дублей и не перезаписывает существующие документы.
- Добавлен личный словарь, который учитывается при следующей проверке орфографии.
- Добавлены проверка формата и лимитов JSON, безопасный вывод импортированного текста, предупреждения при недоступном или заполненном хранилище.
- Подготовлены JSON Schema и учебный пример данных.
- Обновлены модульная, однофайловая и предназначенная для GitHub Pages версии.
- Стандартные имена личных JSON-выгрузок добавлены в `.gitignore`.

Проверки: 83 автоматических сценария на версии для GitHub Pages; дополнительно проверены режимы обращения к API и структура HTML. Визуальная проверка локального HTML в браузере была заблокирована политикой доступа к `file://`.

История использует JSON и `localStorage`. Она не является SQL-СУБД и не синхронизируется между устройствами автоматически; для переноса используется JSON-файл.
