# История изменений

## 14 октября 2026 — документы и JSON

- Добавлен блок «Мои документы»: сохранение, открытие и удаление результатов с подтверждением.
- Подтверждённые результаты автоматически сохраняются в истории браузера.
- Добавлены экспорт и импорт JSON. Повторный импорт не создаёт дублей и не перезаписывает существующие документы.
- Добавлен личный словарь, который учитывается при следующей проверке орфографии.
- Добавлены проверка формата и лимитов JSON, безопасный вывод импортированного текста, предупреждения при недоступном или заполненном хранилище.
- Подготовлены JSON Schema и учебный пример данных.
- Обновлены модульная, однофайловая и предназначенная для GitHub Pages версии.
- Стандартные имена личных JSON-выгрузок добавлены в `.gitignore`.

Проверки: 83 автоматических сценария на версии для GitHub Pages; дополнительно проверены режимы обращения к API и структура HTML. Визуальная проверка локального HTML в браузере была заблокирована политикой доступа к `file://`.

История использует JSON и `localStorage`. Она не является SQL-СУБД и не синхронизируется между устройствами автоматически; для переноса используется JSON-файл.
