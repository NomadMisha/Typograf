# Аудит безопасности корректуры — 14 октября 2026

## Изменения

- Неизвестное словарю слово не заменяется автоматически только из-за одной подсказки или малого расстояния между вариантами. Редактор видит предложения и выбирает сам.
- Для «Крипис» предлагаются «Крепись» и «Кризис»: намерение пользователя в одном примере не считается универсальной автозаменой.
- Сохраняются верхний регистр и разговорное «щас».
- Почта, идентификаторы с подчёркиванием и технические имена файлов защищены от местных правил и неожиданных ответов онлайн-проверки.
- Узкие исключения ограничивают вставку запятых в устойчивых сочетаниях. Правило «в течение» после определения требует единицу времени.
- Финальная точка предлагается на выбор: текст может быть заголовком.
- Постороннее предупреждение больше не считается обнаружением другой размеченной ошибки.

## Сравнение на 50 примерах аудита

Исходная версия взята из коммита `effd071`. Для сравнения использован один и тот же набор с одинаковой контрольной суммой. В нём 31 пример без размеченных ошибок и 19 целевых ошибок. Набор использовался при исправлении правил и является регрессионным, а не независимым.

| Показатель | До | После |
|---|---:|---:|
| Изменения корректного текста | 18 | 0 |
| Корректные примеры с лишними замечаниями | 19 | 4 |
| Неверные автозамены размеченных ошибок | 2 | 0 |
| Обнаруженные целевые ошибки | 17 | 18 |
| Пропущенные целевые ошибки | 2 | 1 |
| Лишние замечания по разметке | 22 | 6 |
| Полное совпадение с эталоном | 26 | 43 |

Обнаружение по черновой разметке: precision 75.00%, recall 94.74%. Это свойства малого набора и его разметки, не проценты качества на произвольном тексте.

Совпадение с эталоном и обнаружение учитываются отдельно: ручная подсказка может обнаружить ошибку, оставив её в тексте до выбора редактора. Замечание должно совпадать с категорией и исходным фрагментом целевой ошибки. Для повторяющихся одинаковых фрагментов потребуется дополнительная разметка позиций.

## Оставшиеся проблемы

- Пропуск: «ВОOБЩЕМ, всё готово.». Смешение похожих латинских и кириллических букв пока не распознаётся как единая опечатка.
- Лишнее по разметке замечание на примере: «Возможно решение задачи.».
- Лишнее по разметке замечание на примере: «Проверка орфографии».
- Лишнее по разметке замечание на примере: «Версия 2».
- Лишнее по разметке замечание на примере: «Список изменений».

Эталоны обоих новых наборов составлены ИИ без проверки редактором и явно помечены как черновые. Редакторский набор `gold-cases.json` остаётся пустым; допуск к пилоту не объявлен. Контекстная нейросеть и производственный сервер на этом этапе не подключались.

## Воспроизведение

Из корня репозитория, Node.js 20+:

```sh
node work/spell-build/evaluate-safety.mjs --html docs/index.html --output /tmp/typograf-safety-current.json --require-clean
node work/spell-build/evaluate-safety.mjs --dataset work/spell-build/safety-holdout.json --html docs/index.html
```

Исходное состояние:

```sh
git show effd071:outputs/typograf-prototype/index.html > /tmp/typograf-baseline.html
node work/spell-build/evaluate-safety.mjs --html /tmp/typograf-baseline.html
```

Приложение и словарь загружаются локально. Онлайн-ответы в специальных сценариях подставлены из тестовых данных; реальные статьи во внешние сервисы не отправляются. Машинные результаты: `SAFETY_BASELINE.json`, `SAFETY_AUDIT.json`, `SAFETY_HOLDOUT.json`.
