# Дополнительный QA-прогон

Проведено: 19–20 октября 2026. Исходное состояние: `bb73c11`.

## Найдено и исправлено

| Сценарий | Ошибка до исправления | После |
| --- | --- | --- |
| `Напр.Москва, абз.Первый.` | Вставлялись пробелы после сокращений вопреки заданному исключению | Исходник сохраняется |
| `Math.PI и System.Text.` | Имена API разбивались пробелом | Известные пространства имён защищены |
| URL со словом `подошол` внутри скобок | В адресе появлялось `подошёл` | Адрес сохраняется |
| Такой же адрес внутри Markdown-ссылки | Менялась цель ссылки | Адрес сохраняется |

Защита адресов консервативна: она сохраняет весь URL до пробела или границы HTML. Прилегающий текст без разделителя тоже может попасть в защищённый фрагмент. Это предпочтительнее автоматической порчи адреса; проверка ссылок на доступность не выполняется.

## Результаты

- Основной набор: **109 сценариев приложения прошли**. В том числе проверены история, атомарный импорт JSON, личный словарь, копирование, подтверждение результата, подсветка, скролл и обработка ошибок сети.
- Дополнительный набор: **30/30**; до исправлений проходили 26/30. Повторная проверка не меняет текст во всех 30 случаях. Позиции замечаний соответствуют фрагментам, подсказка о прямой речи не выполняет замену.
- Нагрузочный пример: **102 400 символов**, 3 200 правок оформления; все 1 600 фрагментов кода сохранились. Около 50–55 мс на этом компьютере в этих прогонах — не гарантия скорости на других устройствах.
- Пройдены `quality-gate.mjs`, тесты оценивания и глубокий синтетический сценарий. Сохранены 40/40 исходников, обнаруживаются 40/40 внесённых ошибок, правильный вариант доступен для 38/40. Gate усилен: он сравнивает не только старую базу, но и принятый снимок качества, включая наличие правильного варианта. Во время проверки исправлен побочный эффект защиты API на подсказку о финальной точке.
- Сервис и серверный/статический режимы прошли тесты с контролируемыми ответами. Публичные сервисы не вызывались для этого прогона.

Все новые примеры синтетические, подготовлены ИИ; они не являются проверенным редактором эталонным набором. Результаты не означают безошибочную корректуру произвольной статьи. Проверки UI выполнялись в JavaScript VM; визуальная проверка браузера в этот прогон не входила. Исходные редакторские эталоны не подменялись.
